<h1>📱 Mobile Sales Analysis Dashboard (Power BI + Excel)</h1>

<!-- 1. Project Title -->
<h2>1. Project Title / Headline</h2>
<h3>📊 Mobile Sales Insight Dashboard — Power BI Analysis</h3>
<p>
An interactive and visually rich dashboard built using <strong>Power BI and Excel</strong> to analyze mobile sales across cities, brands, models, customer ratings, payment preferences, and monthly sales performance.
</p>

<!-- 2. Short Description -->
<h2>2. Short Description / Purpose</h2>
<p>
The Mobile Sales Analysis Dashboard provides a complete end-to-end view of mobile sales performance, helping understand <strong>top-selling brands, customer purchase behavior, city trends, payment patterns, and monthly demand cycles</strong>. 
This dashboard is useful for <strong>retail analysts, business owners, sales teams, and data-driven decision makers</strong>.
</p>

<!-- 3. Tech Stack -->
<h2>3. Tech Stack</h2>
<p>The dashboard was built using the following technologies:</p>
<ul>
  <li>📊 <strong>Power BI Desktop</strong> – Main tool for building visuals and insights.</li>
  <li>🟪 <strong>Power Query</strong> – Used for data cleaning, shaping, and preparing datasets.</li>
  <li>🧠 <strong>DAX Measures</strong> – For KPIs like Total Sales, Total Transactions, Average per Transaction.</li>
  <li>📈 <strong>Excel</strong> – Source dataset used for preprocessing and structured storage.</li>
  <li>🧩 <strong>Data Modeling</strong> – Relationships built between fields such as Mobile Model, Brand, City, Payment Method, etc.</li>
  <li>📁 <strong>File Formats</strong> – .xlsx for data, .pbix for dashboard, .png for screenshots.</li>
</ul>

<!-- 4. Data Source -->
<h2>4. Data Source</h2>
<p><strong>Source:</strong> Internal Excel dataset (Sales_Data.xlsx)</p>
<p>The dataset includes detailed fields such as:</p>
<ul>
  <li>Brand</li>
  <li>Mobile Model</li>
  <li>City</li>
  <li>Customer Name & Age</li>
  <li>Customer Rating</li>
  <li>Date & Day Name</li>
  <li>Payment Method</li>
  <li>Price Per Unit</li>
  <li>Units Sold</li>
  <li>Total Sales</li>
  <li>Transaction & Transaction ID</li>
</ul>

<p>
This structured dataset forms the foundation for performing <strong>city-wise, brand-wise, model-wise, and time-based analysis</strong>.
</p>

<!-- 5. Features -->
<h2>5. Features / Highlights</h2>

<h3>📌 Business Problem</h3>
<p>
Mobile retailers often struggle to understand:
</p>
<ul>
  <li>Which <strong>brands and models</strong> perform best?</li>
  <li>Which <strong>cities</strong> generate the most revenue?</li>
  <li>Which <strong>payment methods</strong> customers prefer?</li>
  <li>How does <strong>sales performance change month-to-month</strong>?</li>
</ul>
<p>Raw Excel data makes it difficult to get quick and actionable insights.</p>

<h3>📌 Goal of the Dashboard</h3>
<ul>
  <li>✔ Deep understanding of mobile sales performance</li>
  <li>✔ Identify top-selling brands and models</li>
  <li>✔ Reveal customer ratings & buying behavior</li>
  <li>✔ Identify city-wise and monthly trends</li>
  <li>✔ Help with stock planning & marketing strategy</li>
</ul>
